# AquaSelf

Sistema em PHP com MySQL para:

- cadastro de animais marinhos;
- monitoramento ambiental;
- conexao com banco de dados;
- exibicao de registros em tabelas.

## Como executar

1. Instale o XAMPP ou WAMP.
2. Coloque a pasta do projeto dentro do diretorio do servidor local.
3. Abra o phpMyAdmin e execute o arquivo `aquaself.sql`.
4. Verifique se o MySQL esta ligado.
5. Acesse `index.php` pelo navegador.

## Arquivos principais

- `index.php`: pagina inicial do projeto.
- `animais.php`: cadastro e listagem de animais marinhos.
- `monitoramento.php`: cadastro e listagem de dados ambientais.
- `conexao.php`: configuracao da conexao com o MySQL.
- `style.css`: visual do site.
- `aquaself.sql`: criacao do banco e das tabelas.
